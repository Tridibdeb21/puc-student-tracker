📖 User Manual & Rules

🎯 Website Purpose

This platform tracks PUC (Programming University Club) students' Codeforces activity including:

  • Daily problem solving progress
  • Weekly performance and trends
  • Contest participation and standings
  • Tag-wise performance analysis
  • Online code compiler for practice

🏆 Weekly Winner Criteria

Weekly winner is selected based on:

  • Must solve at least 5 days in a week
  • Each day must have at least 1 unique solve
  • Tie-breaker: Higher rating wins
  • Displayed at the top of the leaderboard

📊 Leaderboard Rules

  • Sorted by problems solved today (descending)
  • Tie-breaker: Lower rating (ascending)
  • Medals: 🥇 1st, 🥈 2nd, 🥉 3rd
  • Difficulty colors shown with counts
  • Shows ALL students in the list

🏁 Contest Rules

  • Only Non-Div.1 contests in standings
  • Live contests show 🔥 LIVE symbol
  • Contests starting within 24 hours highlighted
  • Shows ALL upcoming contests
  • Shows ALL students in contest standings

💻 Online Compiler

  • Supports C++, C, Java, Python, JavaScript
  • Real-time compilation with Judge0 API
  • Test solutions before Codeforces submission
  • Input/output testing capability
  • Syntax highlighting & code formatting

🎮 Navigation Guide

  • Daily Problem: Random 800-1200 rating problem
  • Leaderboard: Today's performance ranking
  • Online Compiler: Write & test code online
  • Previous Days: Historical leaderboards
  • Weekly Graph: 7-day progress visualization
  • Contests: Upcoming & past contest data

🕐 Time Zone Information

All dates and times are displayed in Bangladesh Time (UTC+6). This includes:

  • Leaderboard dates for previous days
  • Problem submission times
  • Contest start times
  • Weekly graph dates

Note: Duplicate problem solves are filtered from weekly graphs. Each problem is counted only once per student.
